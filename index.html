Help & Shortcuts

Getting Started

  • Click the + button in any column header to create a task
  • Tap the floating + button on mobile for quick task creation
  • Drag tasks between columns to update their status
  • Click any task to edit its details

Sidebar

  • Use the menu button to open the sidebar
  • Click a category or person to filter the board
  • Click it again to clear the filter
  • Toggle the sidebar to icon-only mode for more board space
